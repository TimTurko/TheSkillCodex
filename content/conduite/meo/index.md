# MEO — Méthodes, organisation, animation

Co-traité avec la [[gestion-de-projet|gestion de projet]], qui porte le pilotage d'équipe au fil des phases. Le domaine **MEO** regroupe les pratiques de travail collectif et les disciplines d'ingénieur qui traversent tout le projet : traçabilité, communication, rigueur documentaire.

## Notions couvertes

- [[archivage-projet|Archivage projet]] — organiser et conserver livrables, code et documentation pour qu'ils restent retrouvables
- [[relation-client|Relation client]] — conduire l'échange avec le commanditaire et faire valider aux jalons
- [[revue-de-code|Revue de code]] — faire relire le code aux points critiques, comme routine de qualité collective
- [[unite-si|Unités SI]] — la rigueur du chiffre assorti de son unité dans tous les livrables
- [[cable-management|Cable management]] — organiser et fixer le câblage pour la fiabilité et le diagnostic
